# Plant Disease Detection

Project skeleton for image classification of plant diseases.

## Structure

- `data/train/` - training images
- `data/valid/` - validation images
- `data/test/` - test images
- `notebooks/` - analysis and training notebooks
- `models/` - saved model artifacts
- `outputs/` - generated reports, plots, and predictions

## Notebook

Open `notebooks/Train_Plant_Disease.ipynb` to start training and experimentation.
